## MVP (Фаза 1) — Быстрый запуск

### 1. Запрос на ремонт (фото/видео)

**Клиентская сторона:**
- Загрузка фото/видео проблемы (до 5 файлов)
- Текстовое описание проблемы
- Выбор марки/модели/год авто (или VIN)
- Выбор категории работ (масло, тормоза, подвеска, другое)
- Отслеживание статуса запроса

**Сервизная сторона (админ-панель):**
- Просмотр входящих запросов с медиа
- Формирование оценки стоимости
- Отправка оценки клиенту с разбивкой по работам и запчастям
- Пометка "срочно" / "можно подождать"

### 2. Калькулятор работ

**Как работает:**
```
Клиент выбирает услугу
  → Указывает марку/модель
    → Видит ориентировочную стоимость (от-до)
      → Может добавить несколько услуг
        → Итого с разбивкой: работа + запчасти
```

**Предзаполненный прайс-лист:**
- Смяна на масло: от 30 лв (работа) + масло/фильтр по модели
- Смяна на накладки: от 40 лв (работа) + накладки по модели
- Спирачна течност: от 25 лв (работа) + течност
- Диагностика ходова част: от 30 лв
- И т.д. (мастер заполняет реальные цены)

**Важно:** Цены ориентировочные с пометкой "точная цена после осмотра"

### 3. Онлайн-запись

**Компоненты:**
- Календарь с доступными слотами (по дням/часам)
- Выбор типа работы (влияет на длительность слота)
- Подтверждение записи (push + SMS/Telegram)
- Напоминание за 24 часа и за 1 час
- Возможность отменить/перенести

**Управление слотами (админ):**
- Настройка рабочих часов (Пн-Сб)
- Блокировка слотов (обед, праздники)
- Настройка длительности по типу работы
- Лимит записей в день (кол-во подъёмников)

### 4. Профиль клиента

- Регистрация по телефону (SMS код) или через Telegram
- Мои автомобили (марка, модель, год, VIN, пробег)
- История запросов и записей
- Статус текущего ремонта

### 5. Информация о сервизе

- Адрес + карта (Google Maps интеграция)
- Часы работы
- Контакты (звонок в 1 клик)
- Фото сервиза
- Отзывы клиентов

## Фаза 2 — Расширение

### 6. Telegram-бот

**Функции бота:**
- `/start` — регистрация, привязка телефона
- `/request` — новый запрос (отправить фото + описание)
- `/book` — запись на ремонт (inline-кнопки с датами/временем)
- `/status` — статус текущего ремонта
- `/price` — быстрый расчёт (выбор услуги → цена)
- `/history` — история обслуживания

**Уведомления через бот:**
- Оценка готова — посмотри и реши
- Напоминание о записи
- Машина готова — можно забирать
- Рекомендация по ТО (по пробегу/времени)

### 7. Push-уведомления

- Статус запроса изменён
- Оценка стоимости готова
- Напоминание о записи
- Акции и спецпредложения
- Рекомендация: "Пора менять масло" (по истории)

### 8. Статус ремонта в реальном времени

```
Принят → Диагностика → Согласование → В работе → Контроль качества → Готов
```
- Каждый этап с фото/видео от мастера
- Клиент видит прогресс в приложении и Telegram

## Фаза 3 — Монетизация и рост

### 9. Программа лояльности

- Накопление баллов за каждый визит
- Скидка за рекомендацию друга
- День рождения — спецпредложение
- VIP-статус для постоянных клиентов

### 10. Онлайн-оплата

- Оплата через приложение (карта, Apple Pay, Google Pay)
- Предоплата для бронирования слота
- Разделение оплаты (запчасти отдельно, работа отдельно)

### 11. Маркетплейс запчастей

- Каталог запчастей по модели авто
- Сравнение оригинал vs аналог
- Заказ с доставкой в сервиз к дате ремонта

### 12. AI-диагностика (будущее)

- Загрузил фото → AI определяет проблему
- Предварительная оценка серьёзности
- Рекомендация "срочно / может подождать"
