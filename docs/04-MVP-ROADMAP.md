## Принцип: Запуск за 6-8 недель

Минимум для запуска → обратная связь → итерации.

---

## Неделя 1-2: Фундамент

### Задачи:
- [ ] Настройка проекта (Expo + TypeScript + NativeWind)
- [ ] Настройка бэкенда (Hono + Drizzle + Supabase)
- [ ] Дизайн-система (цвета, шрифты, компоненты из лого)
- [ ] Схема базы данных, миграции
- [ ] Авторизация по телефону (SMS код)
- [ ] Базовая навигация приложения

### Дизайн-система (из лого):
- **Основной цвет:** Тёмно-коричневый (#4A3728) — медведь
- **Акцентный цвет:** Оранжевый (#E8821C) — тепло, доверие
- **Фон:** Светло-серый (#F5F5F5) — чистота сервиза
- **Текст:** Тёмно-серый (#333333)
- **Иконка приложения:** Медведь с ключом (из лого)
