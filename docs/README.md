---

## Краткая сводка для принятия решения

### Что получает сервиз

| Компонент | Описание |
|-----------|----------|
| Мобильное приложение | iOS + Android из одного кода (React Native/Expo) |
| Веб-сайт | Замена нерабочего tvoyatserviz.com, единый дизайн |
| Telegram-бот | Альтернативный канал для клиентов без приложения |
| Админ-панель | Управление записями, ценами, запросами, клиентами |
| Калькулятор работ | Клиент видит ориентировочную стоимость до визита |
| Фото-диагностика | Клиент отправляет фото/видео — получает оценку |
| Онлайн-запись | Календарь с доступными слотами + напоминания |
| 3 языка | Български, Русский, English |

### Почему это работает

1. **Нет конкурентов** — ни один автосервиз в Пловдиве не имеет своего приложения
2. **Низкий порог** — инфраструктура от 100 лв/мес на бесплатных тирах
3. **Быстрая окупаемость** — 23-38 дополнительных клиентов/мес = окупаемость за 5-7 мес
4. **Масштабируемость** — платформа может стать SaaS для других сервизов
5. **Единый опыт** — приложение, сайт и Telegram работают на одном бэкенде
