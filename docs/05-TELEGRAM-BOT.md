## Концепция

Telegram-бот как альтернативный канал для клиентов, которые не хотят устанавливать отдельное приложение. Тот же бэкенд, та же логика, только интерфейс через Telegram.

## Имя бота

`@TvoyatServizBot` (или `@TvoyatServiz_bot`)

## Команды

### Основные:
```
/start           — Регистрация, привязка телефона, выбор языка
/menu            — Главное меню (inline-кнопки)
/request         — Новый запрос на ремонт
/book            — Записаться на ремонт
/price           — Калькулятор цен
/status          — Статус текущего ремонта
/history         — История обслуживания
/mycar           — Мои автомобили
/contact         — Контакты сервиза
/language        — Смена языка (BG/RU/EN)
```

## Уведомления (автоматические)

| Событие | Сообщение |
|---------|-----------|
| Новая оценка | "📋 Готова е оценката за вашия запрос #REQ-0042. Обща сума: 205 лв" |
| Запис потвърден | "✅ Потвърден запис за 20.02 в 10:00" |
| Напомняне 24ч | "⏰ Утре в 10:00 имате запис в Твоят сервиз" |
| Напомняне 1ч | "⏰ След 1 час имате запис. Адрес: ..." |
| Статус обновлён | "🔄 Вашият автомобил е в процес на ремонт" |
| Машина готова | "✅ Вашият BMW 320d е готов! Можете да го вземете." |
| ТО напомняне | "🛢 Време е за смяна на масло (5000 км от последната)" |

## Telegram Mini App (опционально)

Для сложных UI-элементов (калькулятор, календарь) можно использовать **Telegram Mini App** — это веб-приложение внутри Telegram:

- Калькулятор работ → Mini App с красивым UI
- Календарь записи → Mini App с интерактивным выбором
- История ремонтов → Mini App со списком

Это позволит иметь богатый интерфейс без установки отдельного приложения.

## Техническая реализация

```
Telegram API (webhook)
       │
       ▼
  grammY framework (TypeScript)
       │
       ▼
  Общий API сервер (Hono)
       │
       ▼
  PostgreSQL (Supabase)
```

- **Webhook mode** — не polling, экономит ресурсы
- **Middleware** — авторизация, язык, rate limiting
- **Session** — хранение состояния диалога в БД
- **Inline keyboards** — интерактивные кнопки
- **Общие сервисы** — тот же код что и для мобильного API
