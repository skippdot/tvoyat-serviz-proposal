## Языковая поддержка

Приложение поддерживает 3 языка:
- **Български** (основной) — для болгарских клиентов
- **Русский** — для русскоговорящих жителей Пловдива
- **English** — для экспатов

Выбор языка при первом запуске + в настройках профиля.
