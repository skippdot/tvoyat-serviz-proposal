## Видение проекта

Первое в Пловдиве мобильное приложение автосервиза с единым опытом: мобильное приложение + веб-сайт + Telegram-бот.

Клиент отправляет фото/видео проблемы → получает расчёт стоимости → принимает решение → записывается на ближайший слот. Всё в одном месте.

## Услуги (из соцсетей)

- Смяна на масло и филтри (замена масла и фильтров)
- Профилактика и ремонт на ходова част (подвеска)
- Спирачна система (тормозная система):
  - Смяна на накладки (замена колодок)
  - Спирачна течност (тормозная жидкость)
  - Ремонт спирачни апарати (ремонт суппортов)

## Конкурентный анализ (Болгария)

| Платформа | Тип | Цена | Для кого |
|-----------|-----|------|----------|
| E-CAR | Управление сервизом | 65-120 лв/мес | Внутренний менеджмент |
| AutoStory | Софтуер за управление | Неизвестно | Управление + клиентское приложение |
| MyVe | Платформа за автомобили | Неизвестно | 140K юзеров, история авто |

**Ключевое отличие:** Ни одна из этих платформ не предлагает прямой канал "клиент → фото/видео → оценка → запись" для конкретного сервиза. Мы делаем персональное приложение с прямой связью.

## Целевая аудитория

1. **Существующие клиенты** — удержание, удобство записи
2. **Новые клиенты из Пловдива** — привлечение через App Store/Google Play
3. **Русскоговорящие жители** — локализация RU/BG/EN
4. **Молодая аудитория 25-45** — привыкли к мобильным приложениям

## Уникальные преимущества (USP)

1. **Первое в Пловдиве** — само по себе маркетинговый ход
2. **Фото-диагностика** — отправь фото, получи оценку без визита
3. **Прозрачность цен** — калькулятор работ видит клиент
4. **Мгновенная запись** — выбрал слот, подтвердил, приехал
5. **Единый опыт** — приложение, сайт и Telegram работают одинаково
